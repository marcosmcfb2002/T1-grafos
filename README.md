# T1-graffos Project

## Overview
This project, named T1-graffos, is designed to demonstrate the implementation of a software solution using both Java and Python. It includes various components such as source code, documentation, and evidence of results.

## Project Structure
The project is organized into several directories and files:

- **README.md**: This file provides an overview and instructions for usage.
- **acompanhamento/**: Contains milestone documentation.
  - `marco-1.md`: Details related to the first milestone.
  - `marco-2.md`: Details related to the second milestone.
  - `marco-3.md`: Details related to the third milestone.
  - `marco-4.md`: Details related to the fourth milestone.
- **src/**: Contains the source code for the project.
  - `Main.java`: The main entry point for the Java application.
  - `main.py`: An alternative entry point for the application in Python.
  - `classes-ou-modulos/`: Directory for additional classes or modules.
- **evidencias/**: Contains evidence or results related to the project.
  - `accepted.pdf`: A PDF document with project evidence.
- **apresentacao/**: A presentation summarizing the project.
  - `apresentacao.pdf`: The project presentation.
- **dados/**: Contains test cases or data used for testing.
  - `casos-de-teste.txt`: A text file with test cases.

## Usage Instructions
1. Clone the repository to your local machine.
2. Navigate to the `src` directory to find the source code.
3. Choose either the Java or Python entry point to run the application.
4. Review the milestone documents in the `acompanhamento` directory for project progress.
5. Check the `evidencias` directory for results and evidence of the project's outcomes.
6. Use the `apresentacao` directory for a summary of the project findings.
